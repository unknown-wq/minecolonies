# Simple Planes (aircraft integration) -- com/minecolonies/core/compatibility/simpleplanes/**
#
# Deliberately NOT listed below, and it is the one optional integration whose exclusion is decided by
# build.gradle instead of by this file. The difference is that JEI and JourneyMap are parked by choice
# and stay parked; the aircraft package compiles whenever the jar named by `simpleplanes_jar` in
# gradle.properties is present, and is excluded automatically when it is not. Listing it here as well
# would pin it off permanently and there would be no way to build the feature at all.
#
# Everything that names a xyz.przemyk type is inside that one package, and at runtime the mod reaches it
# only through com.minecolonies.api.compatibility.simpleplanes.AircraftCompat, whose default is a
# complete no-aircraft implementation -- MineColonies#onInitialize installs the real one only behind
# FabricLoader.isModLoaded("simpleplanes"), so the mod runs fine with Simple Planes absent.
#
# At COMPILE time that indirection is not complete: MineColonies.java (lines 33, 34, 208, 209, 222, 227)
# and CommandColonyBlastProtection.java (line 9) name types from the package directly, so dropping it from
# the source set leaves exactly 7 errors behind. See the WARNING in build.gradle -- the jar is required to
# build, even though it is not required to run.
